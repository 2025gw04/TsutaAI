システム全体構成

3つの主要コンポーネントが連携して動作します

Web管理画面

ブラウザで動作するプロジェクト管理画面。WBS作成、ガントチャート、カンバンボード、ダッシュボードなど23種類の画面を提供。

Svelte + TypeScript
リアルタイム同期
レスポンシブデザイン

バックエンドAPI

全ての処理を統括するサーバー。データベース管理、AI処理、WebSocket通信、認証・権限管理を担当。

Node.js + Express
RESTful API (155+ endpoints)
JWT認証・RBAC

デスクトップアプリ

Windows上で動作する作業監視アプリ。マウス・キーボード・ウィンドウ・ファイル変更を自動記録し、AIが活動を分析。

C# + WPF
Win32 API監視
自動作業ログ記録

コンポーネント間の連携

Web管理画面 ⇄ バックエンドAPI: WebSocketでリアルタイム双方向通信。タスク更新、AI通知、チーム活動を即座に同期
デスクトップアプリ → バックエンドAPI: 1時間ごとに作業ログを送信。AIが集中度・進捗度・効率性を分析
バックエンドAPI → AI API: 外部LLM（GPT/Groq/Claude等）またはローカルLLMにプロンプトを送信し、回答を取得。オンプレミス運用にも対応

AI機能の処理フロー

ユーザーの操作から結果表示までの流れ

1

ユーザーがAI機能を実行

例: 「WBS自動生成」ボタンをクリック、プロジェクト概要を入力

プロジェクト名: ECサイトリニューアル
期間: 3ヶ月
メンバー: 5名
2

Web管理画面がバックエンドAPIにリクエスト送信

入力データをJSON形式でAPIエンドポイントに送信（JWT認証付き）

POST /api/ai/generate-wbs
Authorization: Bearer eyJhbGc...
{"{"} "projectName": "ECサイトリニューアル", ... {"}"}
3

バックエンドがAI用プロンプトを生成

ユーザー入力とシステムコンテキストを組み合わせ、最適化されたプロンプトを作成

システムプロンプト: あなたは経験豊富なプロジェクトマネージャーです...
ユーザー入力: プロジェクト名: ECサイトリニューアル...
出力形式指定: JSON形式で、各タスクに名前、説明、見積もり工数...
4

AI APIに問い合わせ

外部LLM（GPT/Groq/Claude等）またはローカルLLMにプロンプトを送信。企業のセキュリティポリシーに応じて選択可能

外部LLM
GPT/Groq/Claude等・高度な推論
ローカルLLM
オンプレミス運用・セキュア
カスタム設定
温度・トークン数調整可能
5

AIからの回答を受信・解析

バックエンドがAIの回答をパース（解析）し、データベース形式に変換

AI回答（JSON）:
{"{"} "tasks": [
  {"{"} "name": "要件定義", "duration": 10, "assignee": null ... {"}"},
  {"{"} "name": "デザイン作成", "duration": 15, ... {"}"}
] {"}"}
6

データベースに保存

生成されたタスク、依存関係、見積もりなどをデータベースに保存

PostgreSQL / MySQL / SQLiteに保存
トランザクション管理で整合性を保証
7

Web管理画面に結果を表示

WebSocketでリアルタイムに画面を更新。生成されたWBSがツリービューやガントチャートに表示

WBS生成完了！
25個のタスクが生成されました。ガントチャートで確認できます。
