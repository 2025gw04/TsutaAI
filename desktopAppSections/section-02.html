2. アプリケーション入口

更新基準日: 2026-02-14（`LoginWindow` / `ApiSettingsWindow` / `ProxySettingWindow` を基準に整合）

アプリケーションを開始するための認証と初期設定を行う画面群です。初めてアプリを使う方は、まずこのセクションの設定を行ってから利用を開始してください。

2.1 ログイン画面

アプリケーションを起動すると最初に表示される画面です。登録済みのアカウント情報を入力して、システムにログインします。

画面の目的

TsutaAIサーバーに接続し、あなたのユーザー情報を認証します。ログインに成功すると、ダッシュボード画面に自動的に移動し、本日のタスク一覧が表示されます。

画面構成

要素 説明
ロゴ表示エリア 画面上部にTsutaAIのアプリケーションロゴが表示されます
ユーザーID入力欄 システム管理者から割り当てられたユーザーIDを入力します（開発環境では初期値が入っている場合があります）
パスワード入力欄 ログイン用のパスワードを入力します。セキュリティのため、入力した文字は●印で隠されます
エラーメッセージ表示 ログインに失敗した場合、赤字でエラーの原因が表示されます

ボタン説明

ボタン 説明
ログインボタン 青いボタンです。ユーザーIDとパスワードを入力した後、クリックするとログイン処理が実行されます
プロキシ設定ボタン 社内ネットワークなど、プロキシサーバー経由で接続する環境で使用します
API設定ボタン TsutaAIサーバーの接続先URLを変更する場合に使用します
終了ボタン アプリケーションを終了します

ログイン処理の流れ

  • 入力内容の確認未入力チェックを行います
  • サーバーへの認証リクエスト送信入力した認証情報をサーバーに送信
  • 認証成功時ダッシュボード画面へ移動
  • 認証失敗時エラーメッセージを表示

操作手順

  • ユーザーIDを入力管理者から通知されたユーザーIDを入力欄に入力します
  • パスワードを入力ログイン用パスワードを入力します
  • ログインボタンをクリックボタンをクリックして認証を実行します
  • ダッシュボードへ移動認証成功後、自動的にダッシュボード画面に切り替わります

トラブルシューティング

症状 考えられる原因 対処法
「ログインに失敗しました」と表示される ユーザーIDまたはパスワードが間違っている 入力内容を確認し、正しい情報を再入力してください
「APIサービスが初期化されていません」と表示される サーバー接続設定が未設定 「API設定」ボタンからサーバーURLを設定してください
ログインボタンが反応しない サーバーへの接続処理中 しばらく待つか、ネットワーク接続を確認してください

2.2 API接続設定画面

TsutaAIサーバーへの接続先を設定する画面です。ログイン画面から「API設定」ボタンをクリックすると開きます。

画面の目的

アプリケーションが通信するバックエンドサーバーのURLを設定します。初回起動時や、サーバーのアドレスが変更された場合に使用します。

画面構成

要素 説明
ヘッダー 「API接続設定」というタイトルと、サーバーアイコンが表示されます
API URL入力欄 サーバーのURLを入力するテキストボックスです。通常は http://サーバーアドレス:ポート番号 の形式で入力します
接続テスト結果 「接続テスト」ボタンを押した後、接続の成功・失敗が表示されます

ボタン説明

ボタン 説明
接続テストボタン 入力したURLに対して、実際に接続できるかを確認します。保存前に必ずテストを行うことをお勧めします
保存ボタン 入力したURLを保存してこの画面を閉じます。次回起動時からは保存したURLに自動的に接続します
キャンセルボタン 変更を保存せずにこの画面を閉じます。元の設定が維持されます

操作手順

  • URLを入力管理者から通知されたサーバーURLを入力します
  • 接続テストを実行「接続テスト」ボタンをクリックして接続確認します
  • 結果を確認「接続成功」と表示されることを確認します
  • 保存をクリック設定を保存して画面を閉じます

2.3 プロキシ設定画面

社内ネットワークなど、プロキシサーバー経由でインターネットに接続する環境向けの設定画面です。ログイン画面から「プロキシ設定」ボタンをクリックすると開きます。

画面の目的

企業ネットワークなど、直接インターネットに接続できない環境でアプリケーションを使用する場合に、プロキシサーバーの情報を設定します。

画面構成

要素 説明
ヘッダー 「プロキシ設定」というタイトルと、ネットワークアイコンが表示されます
プロキシ使用チェックボックス 「プロキシを使用する」にチェックを入れると、下の入力欄が有効になります
プロキシサーバーURL入力欄 プロキシサーバーのアドレスを入力します。例: http://proxy.example.com:8080
ユーザー名入力欄 プロキシサーバーで認証が必要な場合に、認証用のユーザー名を入力します
パスワード入力欄 プロキシサーバーで認証が必要な場合に、認証用のパスワードを入力します

ボタン説明

ボタン 説明
保存ボタン 入力したプロキシ設定を保存してこの画面を閉じます
キャンセルボタン 変更を保存せずにこの画面を閉じます

操作手順

  • 「プロキシを使用する」にチェックまずチェックボックスをオンにします
  • プロキシサーバーURLを入力会社のネットワーク管理者から通知されたプロキシサーバーのアドレスを入力します
  • 認証情報を入力（必要な場合）ユーザー名とパスワードを入力します
  • 保存をクリック設定を保存して画面を閉じます
⚠️ 注意事項
  • プロキシ設定は、IT部門やネットワーク管理者から正確な情報を入手してから設定してください
  • プロキシを使用しない環境では、チェックボックスのチェックを外したままにしてください
  • 設定を間違えると、アプリケーションがサーバーに接続できなくなります
