6. 支援・設定・その他

ユーザー支援機能、ヘルスケア、アプリ全体の設定、通知など、作業を円滑に進めるための補助機能群です。

6.1 AIアシスタント画面

チャット形式でAIに相談しながら、タスクの確認や操作を行える画面です。自然な言葉でAIに話しかけるだけで、様々な操作ができます。

画面構成

要素 説明
チャット履歴エリア AIとの会話履歴（ローカルDBに保存、次回起動時に復元）
メッセージ入力欄 Enterで送信、Shift+Enterで改行
@メンション機能 「@」入力で担当タスク一覧を表示、選択で自動入力
変更プレビューパネル AI提案の変更内容を確認してから適用可能

できること（コマンド例）

カテゴリ コマンド例 説明
タスク確認 「担当タスクを確認」 自分のタスク一覧を表示
タスク検索 「タスクを検索：○○」 キーワードでタスクを検索
詳細表示 「@タスク名 の詳細」 特定タスクの詳細情報を表示
進捗更新 「@タスク名 の進捗を50%に更新」 タスクの進捗率を変更
完了設定 「@タスク名 を完了にする」 タスクを完了状態に変更
コメント追加 「@タスク名 にコメント追加：レビュー待ち」 タスクにコメントを追加
ヘルプ 「/help」 コマンド一覧を表示

ボタン説明

  • 送信ボタンメッセージをAIに送信（Enterキーでも可）
  • 適用ボタンAIが提案した変更をサーバーに反映
  • キャンセルボタンAIの提案を適用せずに閉じる
  • 履歴クリアボタンチャット履歴をすべて削除

6.2 ヘルプ依頼画面

特定のタスクについて、チームメンバーに助けを求めるための画面です。

入力項目

項目 説明
タスク選択 ヘルプが必要なタスクをドロップダウンから選択（自分の未完了タスクのみ）
タイトル（必須） ヘルプリクエストの件名
説明（任意） 問題の詳細（状況、試したこと、必要なサポート内容）
緊急度 低（数日以内）/ 中（なるべく早め）/ 高（すぐに対応必要）
AI自動コンテキスト生成 チェックするとAIが状況説明を補足

ボタン説明

  • 作成ボタンヘルプリクエストを作成してチームに送信
  • キャンセルボタン作成せずに画面を閉じる

6.3 メンタルヘルスチェック画面

その日の気分やストレスレベルを記録する画面です。記録後、AIからのアドバイスを受け取れます。

入力項目

項目 説明
気分評価 5段階の絵文字で選択（😞😐🙂😊😄）
ストレスレベル 1（なし）〜5（強いストレス）、色付き数字ボタンで選択
ブロッカー/問題報告 チェックすると詳細入力欄が表示
サポート要請 チェックすると詳細入力欄が表示

ボタン説明

  • 記録するボタン入力内容をサーバーに送信、AIアドバイスを表示
  • キャンセルボタン何も記録せずに画面を閉じる
⚠️ 注意事項 1日1回の記録が推奨されています。同じ日に複数回記録する場合は確認メッセージが表示されます。ブロッカーやサポート要請は管理者に共有される場合があります。

6.4 設定画面

アプリケーションの各種設定を行う画面です。7つのタブで構成されています。

タブ構成

タブ 内容
プロフィール ユーザー名（変更不可）、氏名、メールアドレス、スキル一覧の管理
API接続 TsutaAIサーバーのURL設定、接続テスト
作業フォルダ ファイル変更・Git変更を監視するフォルダの選択
監視設定 マウス・キーボード・アクティブウィンドウ監視、自動保存間隔、アイドル検出時間
休暇管理 休暇期間の登録（スケジュール計算から除外）
Git/SVN バージョン管理システム連携設定（VCSタイプ、パス、認証情報）
通知設定 タスク開始/終了、休憩推奨、AIアラート、サウンドのオン・オフ

スキル管理（プロフィールタブ）

スキル名と習熟度（1-7段階）を登録できます。AIが作業支援の参考情報として使用します。

  • 追加ボタン新しいスキルを追加
  • 更新ボタン選択中のスキルを更新
  • ✕ボタンスキルを削除

監視設定の詳細

項目 選択肢
自動保存間隔 15分 / 30分 / 60分 / 120分
アイドル検出時間 5分 / 10分 / 15分 / 20分

6.5 タスク変更通知ダイアログ

管理者やチームメンバーがタスク内容を変更した場合に表示される通知ダイアログです。

画面構成

要素 説明
ヘッダー 「⚡ タスク変更通知」タイトルと最終更新時刻
タスク情報 変更されたタスクの名前と関連プロジェクト
変更点リスト 変更内容が箇条書きで表示（例：期限変更、優先度変更、ステータス変更）

ボタン説明

  • 確認しましたボタン通知を確認済みとしてマークし、ダイアログを閉じる
⚠️ 注意事項
  • この通知は、作業ウィジェット使用中やダッシュボード表示中にリアルタイムで表示されます
  • WebSocket通信で変更を受信しているため、インターネット接続が必要です
  • 「確認しました」を押すまで通知は消えません
