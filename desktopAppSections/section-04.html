4. 作業実行・タスク管理

更新基準日: 2026-02-14（`WidgetWindow` / `KanbanBoardWindow` / `TaskDetailWindow` 群を基準に整合）

日々の実作業を行う画面群です。タスクの時間計測、ステータス管理、コメントや進捗の更新などを行います。

4.1 作業ウィジェット

ダッシュボードで「今日の作業を開始」をクリックすると表示される、作業中に常に表示されるコンパクトなパネルです。デスクトップの最前面に表示され、作業時間を自動で計測します。

画面の目的

作業ウィジェットは、タスクへの取り組み時間を自動的に記録し、AIからのリアルタイムフィードバックを受け取りながら効率的に作業を進めるための画面です。

画面構成

要素 説明
現在のタスク表示エリア 画面上部に、現在取り組んでいるタスクの名前が大きく表示されます
経過時間タイマー 「00:00:00」形式で現在のタスクに費やした時間がリアルタイムで表示されます（1秒ごとに更新）
進捗バー タスクの見積時間に対する経過時間の割合が視覚的に表示されます
アクティビティ統計 マウスクリック数、キーボード入力数、ファイル変更数などの作業活動が表示されます
AI通知エリア AIが作業状況を分析し、アドバイスや注意点をポップアップで表示します（5分ごと）
タスクリストエリア 本日のタスク一覧が縦に並んで表示されます。ドラッグ＆ドロップで並べ替え可能

ボタン説明

ボタン 説明
一時停止 / 再開ボタン 作業中は「一時停止」、停止中は「再開」と表示。タイマーの停止/再開ができます
完了ボタン 現在のタスクを「完了」としてマークし、次のタスクに自動的に切り替わります
ボードを開くボタン 看板ボード画面を開きます。閉じるとタスク一覧が最新情報に更新されます
本日の作業を終了ボタン その日の作業を終了し、日報作成画面を表示します
通知ボタン 通知履歴画面を開き、未読通知の確認を行います
最小化ボタン（－） ウィジェットをシステムトレイに格納します
閉じるボタン（✕） 作業を中断してダッシュボードに戻ります

自動機能

  • 自動保存作業ログは1時間ごとに自動的にサーバーに保存されます
  • ファイル監視設定で指定した作業フォルダ内のファイル変更を監視し、記録します
  • Git監視作業フォルダがGitリポジトリの場合、コミット履歴も自動的に記録されます

タスク変更通知

管理者がタスク内容を変更した場合、通知ダイアログが表示されます。変更点を確認し、「確認しました」ボタンをクリックして閉じてください。

4.2 看板ボード画面

カンバン形式でタスクを視覚的に管理する画面です。タスクを列間でドラッグ＆ドロップすることで、ステータスを簡単に変更できます。

画面の目的

タスクを「未着手」「進行中」「完了」「保留」の4つのステータスで管理し、視覚的に進捗状況を把握できます。

カンバン列（4列）

列名 色 説明
未着手 緑 まだ作業を開始していないタスク
進行中 黄 現在作業中のタスク（最大3件まで推奨）
完了 濃緑 作業が完了したタスク
保留 赤 何らかの理由で一時的に止めているタスク

タスクカードの情報

  • タスクタイトルタスクの名前
  • WBSコードプロジェクトタスクの場合に表示
  • 見積時間タスクの見積もり時間
  • 経過時間と進捗率現在の進捗状況
  • 進捗バー視覚的な進捗表示

ボタン説明

ボタン 説明
フィルターボタン 現行版では「実装中」メッセージを表示します
個人タスク追加ボタン プロジェクトに属さない個人的なタスクを新規作成します

ドラッグ＆ドロップ操作

  • タスクを掴む移動したいタスクカードをマウスでクリックし、押したままにします
  • 移動先へドラッグ移動先の列（例：「未着手」→「進行中」）までカードをドラッグします
  • ドロップマウスボタンを離すと、タスクのステータスが変更されます

右クリックメニュー

タスクカードを右クリックすると、以下の操作ができるメニューが表示されます：

  • 共通ステータス変更、進捗率変更
  • 個人タスク編集、削除
  • プロジェクトタスクコメント追加、詳細表示
⚠️ 注意 ステータスの変更はサーバーに自動的に送信され、他のメンバーにも反映されます。

4.3 タスク詳細画面

特定のタスクの詳細情報を確認・編集する画面です。4つのタブで構成されています。

画面の目的

タスクの全情報を一覧で確認し、コメントの追加やファイルの添付、作業の開始・完了操作を行います。

ヘッダー情報

  • タスクタイトル
  • プロジェクト名
  • 予定時間
  • 優先度
  • ステータス
  • 担当者
  • 進捗率

タブ構成

タブ 内容
詳細タブ タスクの説明文、見積時間、予定日時の情報
コメントタブ タスクに関するコメント一覧（時系列）。新しいコメントの追加が可能
添付ファイルタブ タスクに関連するファイルの一覧。アップロード・ダウンロードが可能（最大10MB）
履歴タブ タスクに対する操作履歴（ステータス変更、担当者変更など）が時系列で表示

ボタン説明

ボタン 説明
開始ボタン タスクの作業を開始します。画面内で経過時間の計測が始まります
一時停止ボタン 作業を一時停止し、それまでの作業時間をサーバーに記録します
完了ボタン タスクを完了として記録します。進捗が100%に設定されます
閉じるボタン タスク詳細画面を閉じて、元の画面に戻ります

4.4 個人タスク編集画面

個人的なタスク（プロジェクトに属さないタスク）を新規作成または編集する画面です。

画面の目的

プロジェクト外の個人的なToDoを管理するためのタスクを作成します。

入力項目

項目 必須 説明
タスクタイトル 必須 タスクの名前を入力します
説明 任意 タスクの詳細な説明を入力します
優先度 - ラジオボタンで「高」「中」「低」から選択（初期値：中）
見積時間（分） - タスクの完了に必要な予想時間を分単位で入力（初期値：30分）
メモ 任意 自分用のメモを入力できます
初期ステータス - ラジオボタンで「未着手」「進行中」「完了」から選択（初期値：未着手）

ボタン説明

ボタン 説明
保存ボタン 入力内容を保存してタスクを作成（または更新）します
キャンセルボタン 変更を保存せずに画面を閉じます

4.5 タスクコメント一覧画面

タスクに付けられたコメントを一覧で確認し、新しいコメントを追加するための画面です。

画面の目的

タスクに関する議論や連絡事項をチームメンバーと共有します。

画面構成

要素 説明
ヘッダー 対象タスクの名前が表示されます
コメントリスト コメントがタイムライン形式で表示されます。投稿者名と投稿時刻が含まれます

個人タスクではコメント機能は利用できず、プロジェクトタスクのみコメント追加が可能です。

ボタン説明

ボタン 説明
コメント追加ボタン コメント追加ダイアログを開きます
閉じるボタン 画面を閉じて元の画面に戻ります

4.6 コメント追加画面

タスクに新しいコメントを追加するためのシンプルなダイアログです。

画面構成

要素 説明
タスク名表示 コメントを追加する対象タスクの名前が表示されます
コメント入力欄 コメント本文を入力するテキストエリア（複数行可能、500文字まで）
文字数カウント 入力した文字数と上限（500文字）が表示されます

ボタン説明

ボタン 説明
追加ボタン 入力したコメントをサーバーに送信し、タスクに追加します
キャンセルボタン コメントを追加せずに画面を閉じます

4.7 進捗率編集画面

タスクの進捗率（%）をスライダーで簡単に設定できるダイアログです。

画面の目的

タスクの進捗状況を0%〜100%の範囲で設定します。

画面構成

要素 説明
説明文 「このタスクの進捗率を設定してください。」という案内が表示されます
進捗率表示 現在の進捗率が大きな数字で表示されます（例：「50%」）
スライダー 0から100までの範囲で進捗率を設定できます。5%刻みで調整可能

ボタン説明

ボタン 説明
OKボタン 設定した進捗率を保存して画面を閉じます
キャンセルボタン 変更を保存せずに画面を閉じます
