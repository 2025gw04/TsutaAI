5. プロジェクト管理・分析

更新基準日: 2026-02-14（`Project*Window` / `AiAnalysisWindow` / `GrowthTrackingWindow` / `DailyReportWindow` を基準に整合）

長期的なプロジェクトの管理、活動データの分析・振り返りを行う画面群です。

5.1 プロジェクト管理画面

プロジェクトの作成・編集・削除、メンバー管理を行う画面です。

プレビューを見る

プロジェクトカードに含まれる情報

項目 説明
プロジェクト名 プロジェクトのタイトル
ステータス 計画中・進行中・完了・中止
説明 プロジェクトの概要説明文
期間 開始日〜終了日
健全性スコア 0-100の健全性指標

ボタン説明

  • 新規作成新しいプロジェクトを作成
  • 更新一覧を最新情報に更新
  • メンバー管理メンバー管理画面を開く
  • 編集プロジェクト情報を編集
  • 削除プロジェクトを削除

5.2 プロジェクト編集・メンバー管理

プロジェクト編集の入力項目

項目 必須 説明
プロジェクト名 必須 プロジェクトの名称
説明 任意 目的や概要（200文字程度推奨）
開始日 - 開始予定日をカレンダーから選択
終了日 - 終了予定日をカレンダーから選択
ステータス - 計画中/進行中/完了/保留

メンバーのロール種類

ロール 権限
オーナー すべての操作が可能。削除も可能
メンバー タスク作成・編集、コメント追加が可能
閲覧者 閲覧のみ可能。変更不可

メンバー追加時は「ユーザー選択」ダイアログが開き、ユーザー名/氏名で検索して1名ずつ追加できます。

5.3 プロジェクトダッシュボード

プロジェクト全体の状況を視覚的に分析・確認する画面です。4つのタブで構成されています。

プレビューを見る

タブ構成

タブ 内容
ヘルススコア 進捗・納期・チームモラル・ブロッカー・ベロシティの5指標で健全性評価
バーンダウン 日付ごとの残タスク数・残時間・完了量を表形式で確認（チャート可視化は将来実装予定）
クリティカルパス プロジェクト完了に影響する重要タスク経路の分析
スプリント アジャイル開発のスプリント管理

5.4 AI活動分析画面

作業効率をAIが分析し、スコアとアドバイスを表示する画面です。

スコアカード（3指標）

指標 説明
集中度 作業中の集中状態の評価
進捗度 タスク完了ペースの評価
効率性 見積りと実績の乖離度

タブ構成

  • 分析結果タブサマリー、問題点、改善提案、入力統計
  • 履歴タブ過去の分析結果とスコア推移

5.5 成長記録画面

スキルレベル、パフォーマンス、目標管理など自己成長を記録する画面です。

タブ構成

タブ 内容
スキル成長 スキル履歴（推移グラフ）、現在のスキル一覧
パフォーマンス タスク完了率、集中度平均、ヘルプ回数、推移グラフ
貢献記録 チームへの貢献履歴
成長目標 アクティブな目標、完了目標、AI目標提案
AI分析 強み分析、成長機会提案

5.6 日報画面

1日の作業を振り返り、日報を作成・送信する画面です。

プレビューを見る

画面構成

  • AI生成日報エリア完了タスク、進行中タスク、Git活動、ファイル変更、明日の予定を自動生成
  • タスク一覧エリア完了したタスクと残っているタスク
  • AIフィードバックエリア今日の作業分析と明日へのアドバイス

自己評価項目

項目 説明
満足度 顔アイコンで5段階選択（😔🙂😊😄🎉）
達成度 0〜100%のスライダーで入力
集中度 0〜100%のスライダーで入力
難易度 0〜100%のスライダーで入力
学び 0〜100%のスライダーで入力
💡 操作手順 日報内容を確認・編集 → タスク一覧を確認 → 自己評価を入力 → AIフィードバックを確認 → 「送信」をクリック
