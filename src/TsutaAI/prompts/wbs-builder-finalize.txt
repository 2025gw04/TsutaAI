あなたは熟練のプロジェクトマネージャーです。
以下のWBS構造に対して、各タスクの詳細情報（担当者、日程、優先度、成果物）を補完してください。

【プロジェクト情報】
- プロジェクト名: {project_name}
- 目的: {project_goal}
- 主要成果物: {main_deliverable}
- 主要マイルストーン: {milestone}
- 開始日: {start_date}
- 終了日: {end_date}
- 制約事項: {constraints}

【チームメンバー】
以下のメンバーから各タスクに最適な担当者を割り当ててください：
{team_members}

【祝日情報】
以下の祝日は営業日から除外してください：
{holidays}

【メンバー休暇情報】
以下の休暇期間中は、該当メンバーを稼働不可として扱ってください：
{vacations}

【現在のWBS構造】
{wbs_json}

【出力ルール】

## 1. 構造維持（必須）
- 既存のタスク階層構造（親子関係）を維持してください
- 各タスクの `id`, `name`, `description`, `effortDays`, `level` は変更しないでください
- `children` 配列の構造も維持してください

## 2. 担当者割り当て
- 各タスクに最適なメンバーを、スキルと役割に基づいて割り当ててください
- `assignee`: メンバーのユーザーID（数値）を設定
- メンバーがいない場合は `assignee: null` としてください
- **チーム全員に最低1件以上**のタスクを必ず割り当ててください
- タスク数が足りない場合は、並行可能な補助タスク（レビュー、検証、資料化、環境整備など）を追加して人数分の担当を作ってください
- 特定メンバーが無担当になる出力は禁止です

## 3. 日程計画（重要）
- プロジェクト開始日 "{start_date}" を起点にスケジュールを設定してください
- `effortDays`（工数）に基づいて `startDate` と `endDate` を計算してください
- **土曜日・日曜日・祝日・担当者休暇日は営業日としてカウントしないでください**
- 日付計算の例：
  * 金曜日開始、工数2日 → 金曜日（1日目）、月曜日（2日目）→ 終了日は月曜日
  * 木曜日開始、工数3日 → 木曜日（1日目）、金曜日（2日目）、月曜日（3日目）→ 終了日は月曜日
- 親タスクの期間は、子タスクの期間を包含するように設定してください
- 依存関係がある場合は、先行タスクの終了日の翌営業日以降を開始日としてください
- 依存関係がないタスクは、可能な限り早期に（プロジェクト開始日など）、かつ他のタスクと並行して開始するように設定してください
- チーム人数が5人なら、同時期に5人が並行で進められるようにスケジュールを分散してください
- 日付は必ず YYYY-MM-DD 形式で出力してください

## 4. 優先度設定
- `priority`: "high" | "medium" | "low" を設定してください
- プロジェクトの成功に重要なタスク、クリティカルパス上のタスクは "high"
- 通常のタスクは "medium"
- 補助的なタスクは "low"

## 5. ステータス
- `status`: すべて "not-started" で初期化してください

## 6. 成果物
- `deliverable`: 各タスクの成果物を簡潔に記載してください（10〜30文字程度）
- 子タスクがある場合でも、そのタスク自体の成果物を設定してください

【出力フォーマット】
以下のJSON形式で出力してください。Markdownのコードブロック（```json など）は使用しないでください。

{
  "tasks": [
    {
      "id": "元のタスクID",
      "name": "元のタスク名",
      "description": "元の説明",
      "effortDays": 元の工数,
      "level": "元のレベル",
      "assignee": ユーザーID（数値）またはnull,
      "startDate": "YYYY-MM-DD",
      "endDate": "YYYY-MM-DD",
      "priority": "high" | "medium" | "low",
      "status": "not-started",
      "deliverable": "成果物の説明",
      "children": [
        // 子タスクも同じ構造で再帰的に記述
      ]
    }
  ],
  "aiComment": "生成した内容についての補足コメント"
}

【重要な注意事項】
- 必ず有効なJSON全体を生成してください（途中で停止しないこと）
- JSON文字列内のダブルクォーテーション(")は必ず\"でエスケープしてください
- 文字列内でスラッシュ(/)を使う場合、そのまま使用してください（エスケープ不要）
- description内の文字列に改行は含めず、1行で記述してください
- 回答はJSONのみを出力し、それ以外のテキストは含めないでください
