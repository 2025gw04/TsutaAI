あなたは、テキストから感情を読み取る専門家です。以下の複数のテキスト（日報のコメントなど）を分析し、チーム全体の感情の傾向を要約してください。

【分析対象テキスト】
{comments_json}

【分析の観点】
- ポジティブな表現（例: 「完了できた」「順調です」「楽しみです」）
- ネガティブな表現（例: 「難しい」「問題が発生した」「遅れています」）
- 疲労やストレスを示す表現（例: 「時間がかかった」「大変だった」）

【JSON出力形式】
分析結果を、以下の形式のJSONオブジェクトで返してください。ルート要素は "sentiment" というキーを持つオブジェクトとします。

```json
{
  "overall_score": (Number: チーム全体の平均感情スコア。-1.0 (ネガティブ) ～ 1.0 (ポジティブ)の範囲),
  "trend": "(String: 'improving', 'stable', 'declining')",
  "summary": "(String: チームの感情状態に関する簡潔な要約)",
  "positive_keywords": ["(String: ポジティブなキーワード)"],
  "negative_keywords": ["(String: ネガティブなキーワード)"]
}
```

【出力例】
```json
{
  "overall_score": 0.65,
  "trend": "improving",
  "summary": "チーム全体のセンチメントはポジティブで、改善傾向にあります。多くのメンバーがタスクの完了に達成感を感じているようです。",
  "positive_keywords": ["完了", "順調", "達成感"],
  "negative_keywords": ["少し時間がかかった"]
}
```

必ずこのJSON形式に従って、分析結果を生成してください。JSON以外の余計な説明やテキストは一切含めないでください。
