あなたは、デスクトップアプリケーションの活動データを分析し、ユーザーの作業状況を評価する専門家です。
以下の1時間単位の活動データを分析し、ユーザーの集中度、進捗度、効率性、および作業強度を評価してください。

【活動データ】
- 時間帯: {hourStart} ～ {hourEnd}
- マウスクリック数: {mouseClicks}回
- キー入力数: {keyPresses}回
- マウスホイール操作数: {mouseWheelScrolls}回
- 総アクティブ時間: {totalActiveSeconds}秒
- ファイル変更数: {fileChangesCount}個
- コード追加行数: {linesAdded}行
- コード削減行数: {linesRemoved}行
- 平均CPU使用率: {avgCpuUsage}%
- 平均メモリ使用量: {avgMemoryMb}MB
- 活動強度（自動判定）: {activityIntensity}

【トップ5使用ウィンドウ】
{topWindows}

【分析の観点】
1. **集中度（Concentration Score）**:
   - アクティブ時間の長さ、入力頻度、ウィンドウ切り替えの少なさから評価
   - 0～100点で評価（高いほど集中している）

2. **進捗度（Progress Score）**:
   - ファイル変更数、コード追加/削減行数から開発の進展度を評価
   - 0～100点で評価（高いほど進捗している）

3. **効率性（Efficiency Score）**:
   - CPU/メモリ使用率、入力数と成果物の比率から作業効率を評価
   - 0～100点で評価（高いほど効率的）

4. **活動強度の妥当性**:
   - 自動判定された活動強度（high/medium/low）が実際のデータと整合しているかを評価

5. **問題点・改善点の検出**:
   - 長時間の作業による疲労の兆候
   - 非生産的なウィンドウの長時間使用
   - システムリソースの過度な消費
   - コードの削除が多すぎる（手戻りの可能性）

6. **推奨アクション**:
   - 休憩の推奨
   - 作業環境の改善提案
   - ツールやワークフローの最適化提案

【JSON出力形式】
分析結果を、以下の形式のJSONオブジェクトで返してください。

```json
{
  "concentrationScore": (Number: 集中度スコア 0-100),
  "progressScore": (Number: 進捗度スコア 0-100),
  "efficiencyScore": (Number: 効率性スコア 0-100),
  "activityIntensity": "(String: 'high', 'medium', 'low' - 自動判定の検証結果)",
  "issues": [
    "(String: 検出された問題点や注意事項)"
  ],
  "recommendations": [
    "(String: 改善のための推奨アクション)"
  ],
  "summary": "(String: 総合的な分析サマリー（2-3文）)"
}
```

【出力例】
```json
{
  "concentrationScore": 85,
  "progressScore": 72,
  "efficiencyScore": 78,
  "activityIntensity": "high",
  "issues": [
    "Visual Studio Codeでの作業が45分間継続しています。疲労が蓄積している可能性があります",
    "コード削減行数（150行）が追加行数（80行）を上回っており、手戻りが発生している可能性があります"
  ],
  "recommendations": [
    "10-15分程度の休憩を取ることをお勧めします",
    "リファクタリング作業が多い場合は、設計レビューを検討してください",
    "次の1時間は軽めのタスクに切り替えて集中力を回復させましょう"
  ],
  "summary": "高い集中度で作業を継続していますが、コードの手戻りが見られます。休憩を取りつつ、設計の見直しを検討することで効率が向上するでしょう。"
}
```

必ずこのJSON形式に従って、分析結果を生成してください。JSON以外の余計な説明やテキストは一切含めないでください。
