## 達成可能性分析ガイドライン

### 1. achievabilityScore算出
以下の要素を総合的に評価：

**進捗ベース** (40%):
- 現在の進捗率 vs 期待進捗率
- 期待進捗率 = (elapsedDays / totalDays) × 100
- 現在の進捗率 = (completedStoryPoints / targetStoryPoints) × 100

**ベロシティベース** (35%):
- 必要ベロシティ = remainingStoryPoints / remainingDays
- 実績ベロシティ = completedStoryPoints / elapsedDays
- ベロシティ達成率 = 実績 / 必要

**チームコンディション** (25%):
- avgMood, avgStress, avgActivityScoreから算出
- 良好なコンディション → 高スコア

最終スコア = (進捗スコア × 0.4) + (ベロシティスコア × 0.35) + (コンディションスコア × 0.25)

### 2. riskLevel判定
- **low**: achievabilityScore ≥ 0.8
- **medium**: 0.6 ≤ achievabilityScore < 0.8
- **high**: 0.4 ≤ achievabilityScore < 0.6
- **critical**: achievabilityScore < 0.4

### 3. burndownStatus判定
- **ahead**: 現在の進捗率 > 期待進捗率 + 10%
- **on_track**: 期待進捗率 - 10% ≤ 現在の進捗率 ≤ 期待進捗率 + 10%
- **behind**: 期待進捗率 - 20% ≤ 現在の進捗率 < 期待進捗率 - 10%
- **critical**: 現在の進捗率 < 期待進捗率 - 20%

### 4. capacityAssessment判定
- **under_capacity**: avgActivityScore < 50 かつ velocityGap < 0
- **optimal**: 70 ≤ avgActivityScore ≤ 85 かつ velocityGap ≈ 0
- **over_capacity**: avgActivityScore > 85 かつ avgStress < 3
- **burnout_risk**: avgActivityScore > 90 かつ avgStress ≥ 4

### 5. スコープ調整判断
以下の場合にスコープ調整を推奨：
- achievabilityScore < 0.6
- burndownStatus が behind または critical
- teamMoraleImpact が negative
- burnout_risk の兆候あり

**延期候補タスク**:
- 優先度が低い
- 非クリティカルパス
- ストーリーポイントが大きい
- 進捗が0%（未着手）

**加速候補タスク**:
- 優先度が高い
- クリティカルパス上
- すでに進行中（progress > 0）
- ストーリーポイントが小さい（早期完了可能）

### 6. 推奨アクションの優先順位

**High Priority（今すぐ実行）**:
- 深刻なリスクへの対処
- スコープ調整
- チームメンタルヘルス改善

**Medium Priority（今週中）**:
- プロセス改善
- リソース最適化
- 障害の除去

**Low Priority（次スプリント）**:
- 長期的な改善施策
- トレーニング
- ツール導入

## motivationalMessageの作成原則
- 現状を正直に伝えつつ、前向きなトーンを保つ
- 具体的な次のアクションを示す
- チームの努力を認める
- 達成可能な小さなゴールを設定
- "できる"という自信を持たせる

必ずJSON形式で出力してください。分析は現実的で、チームのモチベーションを高めるものにしてください。
