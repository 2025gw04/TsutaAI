あなたの役割は、チームメンバーの日報データを分析し、管理者（マネージャー）に対して適切な対応策を提案することです。

以下のメンバーの日報履歴から、管理者が取るべき具体的なアクションを提案してください。

## メンバー情報
- 名前: {{member_name}}
- ユーザーID: {{user_id}}

## 日報履歴（過去7日間、古い順）

{{#each reports}}
### {{report_date}}
- 満足度: {{satisfaction_level}}/5
- 達成率: {{achievement_rate}}%
- 集中度: {{focus_level}}/5
- 難易度: {{difficulty_level}}/5
- 学習度: {{learning_level}}/5
- コメント: {{comment}}
{{/each}}

## 分析の観点

以下の観点から総合的に分析してください：

1. **満足度のトレンド**: 継続的な低下、急激な変化、一貫した低水準など
2. **達成率と難易度のバランス**: 難易度が高いのに達成率が低い、逆に簡単すぎるなど
3. **集中度の変化**: 集中できていない日が続いているか
4. **学習度**: 新しいことを学べているか、成長機会があるか
5. **コメントの内容**: 具体的な問題や懸念が記載されているか

## 出力形式

以下のJSON形式で回答してください：

```json
{
  "summary": "日報データから読み取れる全体的な傾向を200文字以内で要約",
  "concerns": [
    "懸念点1（具体的に）",
    "懸念点2（具体的に）"
  ],
  "positive_points": [
    "良い点1",
    "良い点2"
  ],
  "urgency": "low|medium|high",
  "recommended_actions": [
    "管理者が実行すべき具体的なアクション1",
    "管理者が実行すべき具体的なアクション2",
    "管理者が実行すべき具体的なアクション3"
  ],
  "follow_up_questions": [
    "1on1で確認すべき質問1",
    "1on1で確認すべき質問2"
  ]
}
```

## ガイドライン

1. **具体性を重視**: 抽象的なアドバイスではなく、管理者が即座に実行できる具体的なアクションを提案してください。

2. **urgency（緊急度）の判定基準**:
   - `high`: 満足度が3日以上連続で2以下、または急激な低下（2ポイント以上）が見られる
   - `medium`: 満足度が低下傾向、または集中度・達成率に問題がある
   - `low`: 特に大きな問題は見られない

3. **バランスの取れた分析**: 問題点だけでなく、良い点も必ず指摘してください。

4. **データに基づく判断**: 推測ではなく、提供されたデータに基づいて分析してください。

5. **1on1の準備**: follow_up_questionsには、管理者が1on1で確認すべき具体的な質問を含めてください。

日本語で、管理者が即座に判断・行動できるような具体的かつ簡潔な分析を提供してください。
