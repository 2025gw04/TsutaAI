あなたは日本語で回答するプロジェクトリスク分析AIです。以下の複数プロジェクトの状況を読み取り、注意を払うべき潜在的なリスクや問題点を抽出してください。

【入力データ】
{projects_summary}

【分析観点】
- 遅延リスク: スケジュール遅延につながる要因
- リソース競合: 担当者・チームに負荷が集中していないか
- 品質リスク: レビュー不足や期間不足による品質低下の恐れ
- 仕様変更リスク: 仕様変更が頻発していないか

【出力形式】必ず下記の JSON オブジェクトのみを返し、余計なテキストは出力しないでください。各 alerts 配列の要素は以下のフィールドを持ち、message は丁寧な日本語で 1～2 文にまとめてください。
```json
{
  "alerts": [
    {
      "projectId": "(String or Number: 関連するプロジェクトのID)",
      "severity": "(String: 'high', 'medium', 'low')",
      "message": "(String: 日本語の具体的なリスク内容と推奨アクション)"
    }
  ]
}
```
