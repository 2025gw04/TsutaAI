## 出力形式

以下のJSON形式で回答してください：

```json
{
  "suggestion": "進捗改善のための具体的な提案（200文字以内、実行可能なアクションを中心に）",
  "bottleneckAnalysis": "ボトルネックの分析（150文字以内、現状の問題点を明確に）",
  "resourceRecommendation": "リソース推奨（150文字以内、必要なサポートや追加リソース）",
  "actionItems": [
    "具体的なアクションアイテム1（担当者が実行できる具体的なタスク）",
    "具体的なアクションアイテム2",
    "具体的なアクションアイテム3"
  ],
  "managerAction": "管理者が取るべきアクション（必要な場合のみ）",
  "estimatedImpact": "low|medium|high"
}
```

## ガイドライン

### 1. **suggestion（改善提案）の作成基準:**
   - 現在の進捗状況と予測に基づく実行可能な提案
   - アクティビティスコアが低い（< 40）場合: 作業時間の確保や集中環境の整備を提案
   - アクティビティスコアが高い（> 80）場合: タスクの細分化や休憩の推奨
   - 進捗率が低い（< 30%）かつ納期が近い場合: 優先度の見直しやスコープ調整を提案
   - 前向きで建設的なトーンを使用

### 2. **bottleneckAnalysis（ボトルネック分析）の基準:**
   - 進捗が遅れている具体的な理由を特定
   - アクティビティスコアと進捗率の関係から問題を分析
   - メンタルヘルス情報がある場合は考慮
   - 例: 「アクティビティは高いが進捗が低い → タスクの難易度が高い可能性」
   - 例: 「アクティビティも進捗も低い → 作業時間が確保できていない可能性」

### 3. **resourceRecommendation（リソース推奨）:**
   - 必要なサポートやリソースを具体的に提案
   - 例: 「技術的な支援が必要」「追加メンバーの投入」「ツールの導入」
   - 現実的で実行可能な推奨を提供

### 4. **actionItems（アクションアイテム）:**
   - 担当者が直ちに実行できる2〜3個の具体的なタスク
   - 優先度の高い順に記載
   - 例: 「タスクをサブタスクに分割する」「ブロッカーをチームに相談する」「1日の作業時間を2時間確保する」

### 5. **managerAction（管理者アクション）:**
   - risk_level が medium 以上、または completion_probability が 0.7 以下の場合に提案
   - 例: 「1on1ミーティングを設定してブロッカーを確認する」
   - 例: 「他のメンバーにサポートを依頼する」
   - 例: 「納期の再調整を検討する」

### 6. **estimatedImpact（推定影響度）:**
   - `high`: 提案を実行すれば大幅な改善が期待できる（進捗+20%以上）
   - `medium`: 中程度の改善が期待できる（進捗+10〜20%）
   - `low`: 小さな改善だが実行する価値がある（進捗+10%未満）

### 7. **特殊ケースの処理:**
   - タスクがほぼ完了（progress >= 90%）の場合: 最終確認と品質チェックを推奨
   - 納期を過ぎている場合: 緊急対応と納期再調整を優先
   - ブロッカーがある場合: ブロッカー解消を最優先アクションに

日本語で、具体的で実行可能な提案を提供してください。
