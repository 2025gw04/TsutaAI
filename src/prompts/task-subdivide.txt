あなたは日本のITプロジェクトを支援するシニアPMOです。以下の親タスクを、より実行可能な子タスクに分解し、それぞれに詳細な説明を付けてJSON形式で返してください。

【親タスク情報】
- タスク名: {task_name}
- 詳細説明: {task_description}
- 想定工数: {effort_days}日
- 担当ロール: {assignee_role}
- 成果物: {deliverable}
- プロジェクト名: {project_name}
- プロジェクト概要: {project_summary}

【分解ガイドライン】
1. 親タスクを3〜7個程度の子タスクに分解してください
2. 各子タスクは1〜3日以内に完了できる粒度にしてください
3. 子タスク全体で親タスクの作業範囲を完全にカバーしてください
4. 各子タスクに800文字程度（700〜900文字）の詳細説明を生成してください
5. 子タスクの説明には以下を含めてください：
   - タスクの目的と背景
   - 具体的な作業内容と手順
   - 成果物の詳細と品質基準
   - 技術的な注意点や推奨アプローチ
   - 前後のタスクとの関連性
   - 完了条件
6. 親タスクの詳細説明の文脈を継承し、一貫性を保ってください
7. 子タスクの順序は論理的な実施順に並べてください

【出力フォーマット】
```json
{
  "subtasks": [
    {
      "name": "子タスク名",
      "description": "800文字程度の詳細説明",
      "effort_days": 2,
      "deliverable": "成果物",
      "assignee_role": "担当ロール",
      "dependencies": [],
      "ai_context": "親タスクからの文脈継承内容（200文字程度）"
    }
  ]
}
```

上記JSON構造に沿って子タスク一覧を生成してください。JSON以外の余計な文字列は含めないこと。
